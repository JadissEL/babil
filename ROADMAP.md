# VisaFlow v5.0 : SaaS Product Roadmap

## 1. Vision & MVP Definition
**Target:** Moroccan self-employed professionals (Auto-entrepreneurs) and freelancers seeking European mobility.
**Value Proposition:** AI-driven predictive visa audit based on real-world friction and OSINT data.

### MVP Features (Current Progress)
- [x] Predictive Scoring (Official vs. Brutal Reality)
- [x] Optimal Strategy Engine (Phased application roadmap)
- [x] Journey Mapping (Friction points & hidden risks)
- [x] Real-time OSINT reality checks (Darija-enhanced feedback)

## 2. Scalable Architecture
- **Frontend:** React/Next.js (currently Vanilla JS for speed).
- **Backend:** Node.js + PostgreSQL for user profile management.
- **AI Engine:** Integration with LLMs (Gemini/GPT-4) for personalized document auditing.
- **Data Pipeline:** Automated OSINT crawlers for TLS/BLS appointment availability.

## 3. Monetization Model
- **Freemium:** Access to global scores and overview.
- **Premium (Audit One):** 299 MAD - Full "Brutal Reality" audit for 1 country + custom journey map.
- **Expert Strategy (Full Path):** 599 MAD - 12-month phased roadmap with fallback strategies.
- **B2B:** Dashboard for travel agencies to manage client expectations.

## 4. Admin Dashboard (Future)
- Interface for manual data updates (confidence scores, hidden risks).
- Monitoring of "Mafia des RDV" price fluctuations and bot detection status.
- User feedback loop for "Community-based insights" validation.

## 5. Information Compression Rules
- **Rule 1:** Zero repetition across UI layers.
- **Rule 2:** Every sentence must be decision-relevant.
- **Rule 3:** High density = Bullet points + Progress bars > Paragraphs.
